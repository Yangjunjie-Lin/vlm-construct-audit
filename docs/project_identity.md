# Project Identity

## Repository

`vlm-construct-audit` is a new Git repository with no shared Git ancestry with ReCoAlign.
Its working title is *Intervene Before You Infer: Validity-Aware Auditing for Behavioral
Claims in Vision-Language Models*.

The labels VGCA, VLM-CVA, Validity-Gated Causal Audit, and Vision-Language Construct
Validity Audit are provisional search handles, not established contribution claims.

## Scientific target

The project asks whether a VLM behavioral intervention experiment has adequate
intervention validity, measurement validity, and cross-condition stability to support a
scope-bounded behavioral mechanistic claim. Input/output behavior alone does not identify
an internal mechanism.

Tier 0 calibrates the audit against systems with known states. It is engineering and
method calibration only. Tier 1 requires a frozen preregistration, three independently
selected open-weight VLM families, and a legally redistributable real-image transport set.
