# Multiplicity and Path B Error-Control Audit

## Global-null behavior

Under six independent cells, each naïve-positive event has probability 0.025 because the frozen
definition is a positive estimate with an unadjusted two-sided zero-effect p-value below 0.05. The
exact probability of at least two such cells is 0.008767.

Shared scenes and serializations make the cells correlated. Across the requested estimator-
correlation grid, independent simulation put the same probability between 0.00875 and 0.04464.
At within-model correlation 0.90 and between-model correlation 0, almost all of the 0.04464 event
probability came from two serializations of the same model family (0.04335). Those cells cannot be
called independent replications.

## Mechanical ambiguities

Path B is not deterministically implementable as frozen:

- “independent model×serialization cells” is undefined; the two serializations of one model share
  weights and scenes, and all six cells share scenes.
- It does not explicitly require naïve-positive cells from two model families, even though another
  prose clause says the pattern may not be attributable to one model.
- “not attributable to one template, one model, or one serialization” has no threshold or
  algorithm.
- “the downgrade agrees with the frozen known-DGP P3 decision logic” is a judgement, not a code
  predicate.
- The denominator and tie behavior for “more than half of claim-scope changes are INCONCLUSIVE”
  are not fully specified, and valid P3 code normally emits an explicit gray label instead of
  `INCONCLUSIVE`.
- Stable Path's “not driven by one serialization” and “leave-one-family-out pooled direction” do
  not define the driver statistic or pooling weights.

Holm correctly controls the six confirmatory minimum-effect claims when applied as specified.
Path B explicitly waives Holm support and is described as audit value, not a family-wise positive
claim, but its occurrence can still be generated by multiplicity and correlation and can trigger
a scope-changing successor program. The current prose leaves post-result discretion.

Decision on this dimension: `AUDIT_CONDITIONAL_PREINFERENCE_AMENDMENT`.
